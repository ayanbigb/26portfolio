# Projects site

A simple static portfolio page. Open `index.html` locally, or publish this folder with GitHub Pages.

## Publish on GitHub Pages

1. Create a GitHub repository and push these files.
2. In the repository, open **Settings → Pages**.
3. Set the source to **Deploy from a branch**, then select `main` and `/ (root)`.
4. Save. GitHub will provide the public site URL shortly after deployment.
